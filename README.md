# Mi IP

Suite de herramientas de red como app web (PWA) instalable en iOS. Todo gratuito, sin registro, sin claves de API y sin servidores propios.

## Herramientas

1. **Mi IP** — IPv4 e IPv6 públicas con botón de copiar; ciudad, región, país, continente, código postal, zona horaria y hora local, ISP, organización, ASN, coordenadas y bandera (por versión de IP, copiado por campo y total); mapa de ubicación aproximada.
2. **Prueba de velocidad** — descarga, carga, latencia y jitter con gráficas en vivo, medidor, nodo Cloudflare más cercano y evaluación.
3. **Consultar IP** — geolocalización, ISP y red de cualquier IP pública, con mapa y accesos directos a WHOIS/ASN/DNS inverso/listas negras.
4. **WHOIS de IP** — RDAP al registro regional (ARIN, LACNIC, RIPE, APNIC, AFRINIC): titular, rango, CIDR, fechas y contactos (incluido abuso).
5. **Consultar ASN** — titular, registro, país, estado BGP y prefijos anunciados (RIPEstat).
6. **Consulta DNS** — A, AAAA, CNAME, MX, NS, TXT, SOA, CAA, SRV vía DNS-over-HTTPS, con estado DNSSEC.
7. **DNS inverso** — registro PTR con verificación directa (forward-confirmed).
8. **Correo del dominio** — MX, SPF, DMARC y DKIM con evaluación de la política.
9. **Listas negras** — 12 DNSBL públicas en paralelo.
10. **Analizar IP** — pública/privada/especial (RFC 1918, CGNAT, loopback, multicast…), clase, decimal/hex/binario/octal, PTR, IPv6 expandida/comprimida, prefijos.
11. **Calculadora de subred** — CIDR o IP+máscara: red, broadcast, wildcard, rango de hosts, división en subredes.
12. **IP aleatoria** — IPv4/IPv6, opción de solo públicas.
13. **IP del router** — cómo hallar la puerta de enlace por sistema, accesos a direcciones habituales y tabla por fabricante/proveedor.
14. **Mi conexión** — protocolo HTTP, versión TLS, nodo, país, datos del navegador y dispositivo, y ping HTTP a cualquier host.

## Fuentes (todas gratuitas y sin clave)

ipify · ipwho.is (respaldo ipapi.co) · rdap.org → registros regionales · RIPEstat · Cloudflare 1.1.1.1 (DNS-over-HTTPS) y speed.cloudflare.com · OpenStreetMap/Leaflet.
