# Mi IP

App web (PWA) instalable en iOS que muestra tu dirección IP pública y sus detalles.

## Funciones

- IPv4 e IPv6 públicas, cada una con botón de copiar (indica cuando la red no expone IPv6).
- Detalles por versión de IP (pestañas IPv4 / IPv6): ciudad, estado/región, país, código postal, zona horaria, proveedor (ISP), organización, ASN y coordenadas — cada campo con su propio botón de copiar.
- "Copiar todo": resumen completo en texto plano.
- Mapa con la ubicación aproximada (Leaflet + OpenStreetMap).
- Botón de actualizar para reconsultar (útil al cambiar de Wi-Fi a datos móviles).

## Fuentes de datos

- IP: api.ipify.org / api6.ipify.org / api64.ipify.org
- Geolocalización e ISP/ASN: ipwho.is, con respaldo en ipapi.co
- Sin registro, sin clave de API, sin servidores propios. La geolocalización por IP es aproximada.
